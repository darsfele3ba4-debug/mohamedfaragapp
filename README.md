# متابعة الطلاب (النسخة المبسطة): أ/ محمد فرج منصور

داخل كل مجموعة يسجل المدرس لكل حصة ولكل طالب:
الحضور أو الغياب، وحل الواجب، ودرجة امتحان الحصة، وملاحظات، ودفع المصاريف من عدمه، ومبلغ المصاريف.
ويمكنه الإدخال أو التعديل الجماعي لكل الطلاب أو للطلاب المحددين مرة واحدة.
ولي الأمر يرى كل هذه البيانات من رابط البوابة بعد كتابة كود الطالب.

## الإعداد
1. Google Sheet جديد ← Extensions ← Apps Script ← الصق `apps-script/Code.gs` ← احفظ.
2. Deploy ← New deployment ← Web app ← Execute as: **Me** ← Who has access: **Anyone** ← Deploy ← انسخ الرابط (ينتهي بـ `/exec`).
3. ضع الرابط في `config.js` داخل `apiUrl`.
4. ارفع محتويات المجلد على GitHub، ثم فعّل Settings ← Pages ← Deploy from a branch ← main ← / (root).
5. افتح التطبيق ← «إعداد أول مرة» ← اختر كلمة المرور.

- رابط ولي الأمر: `رابط-التطبيق/#/p` (ويمكن إرساله جاهزاً بالكود من صفحة الطالب عبر واتساب).
- عند تعديل `Code.gs` لاحقاً: Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy (يبقى نفس الرابط).
- عند رفع تحديث لملفات التطبيق: غيّر `VERSION` في `sw.js`.
- نسيت كلمة المرور؟ شغّل `resetPassword()` من محرر Apps Script.
